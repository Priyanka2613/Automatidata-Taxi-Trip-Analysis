# NYC Taxi Trip Analysis | Exploratory Data Analysis

### Python | Pandas | NumPy | Matplotlib | Seaborn | Data Visualization

## Project Overview

This project explores New York City taxi trip data to identify travel patterns, examine trip distances, and understand differences in taxi ride activity across drop-off locations.

The analysis was completed as part of the **Google Advanced Data Analytics Professional Certificate on Coursera**, using Python and Jupyter Notebook.

The project follows the PACE framework: Plan, Analyze, Construct, and Execute.

## Business Objective

The objective is to explore taxi trip data and generate insights that could support data-driven business decisions.

Key questions include:

- How do taxi trip distances vary across drop-off locations?
- Which drop-off locations receive the most taxi rides?
- Are there noticeable differences in average trip distance between locations?
- How can visualizations help identify patterns and opportunities for further analysis?

## Tools and Technologies

- **Python:** Data analysis and statistical exploration
- **Pandas:** Data manipulation and aggregation
- **NumPy:** Numerical calculations and simulation
- **Matplotlib:** Data visualization
- **Seaborn:** Statistical visualization
- **Jupyter Notebook:** Interactive analysis and documentation

## Dataset

The project uses the **2017 Yellow Taxi Trip Data** provided for the Automatidata course activity.

The dataset includes information about taxi trips, including trip distances and drop-off location identifiers.

## Exploratory Data Analysis

The project includes:

1. Exploring the dataset's structure and relevant variables.
2. Examining taxi trip distances using descriptive statistics and visualizations.
3. Comparing average trip distances across drop-off locations.
4. Analyzing the distribution of taxi rides by drop-off location.
5. Creating boxplots, scatter plots, and bar charts.
6. Using simulated coordinate data to explore relationships between endpoints and average distances.

## Key Findings

### 1. Variation in Taxi Demand

Taxi ride activity differs across drop-off locations. Some locations receive substantially more rides than others.

### 2. Differences in Average Trip Distance

Average trip distances vary across drop-off locations, suggesting different travel patterns.

### 3. Drop-off Location Coverage

The dataset contains **216 unique drop-off location IDs**, with values ranging from 1 to 265. These IDs are not consecutive.

### 4. Importance of Data Visualization

Visualizations make it easier to identify differences in ride frequency, compare trip distances, and investigate unusual patterns.

## Business Insights

The findings could help support:

- Understanding differences in taxi demand across locations.
- Identifying areas for further investigation.
- Exploring opportunities for improved resource allocation.
- Developing additional analyses involving revenue, fares, and time-of-day demand.

These are potential applications of the analysis, not verified business outcomes.
